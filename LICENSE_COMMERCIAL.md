# Voice API Commercial License

The [Voice API License](./LICENSE.md) covers most use cases: self-hosting for your own products, internal business use, personal projects, and non-commercial redistribution.

If your use case falls outside those terms, you need a **Voice API Commercial License**.

## When you need a commercial license

You must obtain a separate commercial agreement if you want to:

- **Sell or monetize Voice API as a product** — for example, white labeling the platform and charging customers for access
- **Host Voice API as a paid service** — running a multi-tenant hosted version where end users pay you to use the API or dashboard
- **Embed Voice API in a commercial offering** where the value of your product or service derives substantially from Voice API functionality, and you charge for that offering

## What is allowed without a commercial license

The Voice API License already permits:

- Self-hosting Voice API to power voice features in your own application (using your own Twilio, LiveKit, and AI credentials).
- Building agents, placing calls, and managing call logs for your company's internal or customer-facing products.
- Offering consulting, integration, or support services around Voice API.
- Contributing code, building SDK integrations, and distributing the software for free and non-commercial purposes.

## How to get a commercial license

Commercial licenses are negotiated on a case-by-case basis. Open an issue or contact the maintainers to discuss your use case, terms, and pricing:

**GitHub:** [keyman500/voice-api/issues](https://github.com/keyman500/voice-api/issues)
